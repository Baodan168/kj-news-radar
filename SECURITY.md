# Security Policy

## Supported Versions

We recommend always using the latest version from the `master` branch.

## Reporting a Vulnerability

This project aggregates publicly available news content from cross-border e-commerce sources. If you discover a security concern:

1. **Do not** open a public issue
2. Email the maintainer or open a private security advisory on GitHub

Please include:
- A description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact

We will acknowledge receipt within 48 hours and work on a resolution.

## Scope

Security concerns relevant to this project include:
- Data source authentication or API key exposure
- Script injection via RSS/OPML feed content
- Unauthorized access to GitHub Actions secrets or deployment tokens

## Out of Scope

- News content accuracy or timeliness (handled via source health monitoring)
- General questions about cross-border e-commerce policies
